① 概要

本アプリは、日々のタスクを管理するためのWebアプリケーションです。

ユーザー登録・ログイン機能を備え、ユーザーごとにタスクを管理できます。タスクにはカテゴリ（Main/Sub）や実行時間を設定でき、優先度を分けながら管理できます。

特徴
ユーザー認証機能
タスクの追加・閲覧・削除
Main/Subによるカテゴリ分け
タスク時間の設定
レスポンシブデザイン対応
